UNDERSTANDING AYURVEDA

The Three Doshas

In Ayurveda, Vata, Pitta, and Kapha are three important concepts used to describe different body and mind characteristics.

〰

Vata

Air + Space

Vata is traditionally associated with movement, activity, and communication.

☀

Pitta

Fire + Water

Pitta is traditionally associated with heat, transformation, and digestion.

❋

Kapha

Earth + Water

Kapha is traditionally associated with stability, structure, and support.

KNOWLEDGE BASE

Understanding the Rules

The system uses predefined IF–THEN rules and weighted scores to calculate the classification result.

01

Vata Rules

Examples of rules used by the system:

  • IF Dry Skin, THEN Vata +2
  • IF Cold Hands/Feet, THEN Vata +2
  • IF Constipation, THEN Vata +2
  • IF Bloating, THEN Vata +1
  • IF Anxiety, THEN Vata +1
  • IF Insomnia, THEN Vata +1
02

Pitta Rules

Examples of rules used by the system:

  • IF Acidity, THEN Pitta +2
  • IF Irritability, THEN Pitta +2
  • IF Inflammation, THEN Pitta +1
  • IF Sweating, THEN Pitta +1
03

Kapha Rules

Examples of rules used by the system:

  • IF Oily Skin, THEN Kapha +2
  • IF Weight Gain, THEN Kapha +2
  • IF Lethargy, THEN Kapha +1
  • IF Water Retention, THEN Kapha +1
